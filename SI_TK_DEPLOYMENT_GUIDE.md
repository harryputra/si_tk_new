## 🛠️ Langkah Deployment

### 1. Persiapan di Windows (Antigravity IDE)
Pastikan semua file Docker sudah siap. Saya sudah menyiapkan:
- `Dockerfile` & `docker-compose.yml` (Standar Playbook)
- `run.sh` (Template Universal)
- `.env.example` (Docker-ready)

**Push perubahan terakhir:**
```powershell
cd E:\AntiGravityProject\si_tk_new
git add .
git commit -m "chore: align with server deployment playbook"
git push origin main
```

### 2. Clone & Setup di Server
Masuk ke server via SSH:
```bash
ssh trinpolman@100.71.18.61
cd ~/projects
git clone https://github.com/harryputra/si_tk_new.git si_tk_new
cd si_tk_new
chmod +x run.sh
```

### 3. Konfigurasi Environment
Salin dan sesuaikan `.env`:
```bash
cp .env.example .env
nano .env
```
**Sesuaikan bagian ini:**
```dotenv
APP_URL=https://tk.trin-polman.id
HTTP_PORT=8100
DB_PORT_EXTERNAL=5434
DB_PASSWORD=strong_password_here
```

### 4. Jalankan One-Shot Runner
Jalankan skrip untuk membangun dan menyalakan semua service:
```bash
./run.sh up
```

### 5. Wire ke Cloudflare Tunnel
1.  **Hubungkan Network**:
    ```bash
    docker network connect si_tk_net cloudflare-tunnel
    ```
2.  **Tambah Hostname di Dashboard**:
    - Buka [Zero Trust Dashboard](https://one.dash.cloudflare.com) -> Networks -> Tunnels.
    - Pilih tunnel `trin-polman`.
    - **Add a public hostname**:
        - Subdomain: `tk`
        - Domain: `trin-polman.id`
        - Service: `HTTP`
        - URL: `http://si_tk_web:80` (Arahkan ke container web)

### 6. Verifikasi Akhir
Cek apakah sudah live:
```bash
curl -I https://tk.trin-polman.id/
```

## 📋 Maintenance Cheat Sheet
- **Lihat Status**: `./run.sh status`
- **Lihat Log**: `./run.sh logs app`
- **Update Kode**: `git pull && ./run.sh rebuild`
- **Backup DB**: Tambahkan baris berikut ke `crontab -e`:
  ```cron
  0 2 * * * docker exec si_tk_db pg_dump -U postgres si_tk_attauhid | gzip > ~/backups/si-tk-$(date +\%F).sql.gz
  ```
